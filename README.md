# WALES FLOOR FINISH

Static business website for WALES FLOOR FINISH. The public website is deployed with
GitHub Pages at <https://olawaleboy.github.io/wales-floor-finish/>.

## Update the website

Edit the site files and project photos in this folder. To publish updates from a
terminal, run:

```sh
git add .
git commit -m "Update website"
git push
```

GitHub Pages publishes updates from the `main` branch.
